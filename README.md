# proberow

Probe CSV/TSV row tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/proberow/

## Install / run

```bash
git clone https://github.com/theworker02/proberow.git
cd proberow
node src/cli.js
node --test
```
